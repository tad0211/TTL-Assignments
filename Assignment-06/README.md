# Assignment 06 – Traffic Sign Classification using CNN

## Overview

This assignment focuses on **traffic sign classification using a Convolutional Neural Network (CNN)**.

The objective is to apply deep learning and computer vision techniques to automatically classify traffic sign images.

## Objective

- Prepare image data for deep learning.
- Preprocess traffic sign images.
- Build a CNN-based classification model.
- Train the neural network.
- Evaluate classification performance.

## Approach

The workflow includes:

1. Loading the traffic sign dataset.
2. Image preprocessing.
3. Preparing training and testing data.
4. Building a CNN architecture.
5. Training the model.
6. Evaluating model performance.
7. Visualizing predictions and results.
