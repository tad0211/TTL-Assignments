# Tata Technologies TechPulse FY-26 – Applied AI & ML

This repository contains the assignments completed as part of the **Tata Technologies TechPulse FY-26 Applied AI & ML program**.

The assignments cover a progressive range of Artificial Intelligence and Machine Learning concepts, including machine learning fundamentals, data preprocessing, predictive modeling, deep learning, computer vision, Natural Language Processing, Explainable AI, and MLOps.
