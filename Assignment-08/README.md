# Assignment 08 – Sentiment Analysis using Bi-LSTM

## Overview

This assignment focuses on **sentiment analysis using a Bidirectional Long Short-Term Memory (Bi-LSTM) neural network**.

The application is designed around automotive feedback and demonstrates how Natural Language Processing can be used to classify textual feedback into sentiment categories.

## Objective

- Clean and preprocess textual feedback.
- Tokenize text and construct a vocabulary.
- Convert text into numerical sequences.
- Apply sequence padding.
- Build a Bidirectional LSTM model.
- Classify feedback into sentiment categories.
- Evaluate model performance.

## Sentiment Classes

The model uses three sentiment categories:

- Positive
- Neutral
- Negative

## Approach

The workflow includes:

1. Automotive feedback dataset creation/loading.
2. Text cleaning and preprocessing.
3. Tokenization.
4. Vocabulary construction.
5. Sequence encoding and padding.
6. Bi-LSTM model construction.
7. Model training.
8. Performance evaluation.
9. Confusion matrix and classification report.
10. Sentiment prediction on new feedback.
