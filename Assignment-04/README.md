# Assignment 04 – Vehicle Price Prediction

## Overview

This assignment develops a machine learning model for **vehicle price prediction** using automotive attributes.

The objective is to understand how vehicle characteristics can be used to estimate vehicle prices through supervised learning.

## Objective

- Prepare vehicle data for modeling.
- Select relevant predictive features.
- Train a regression model.
- Generate vehicle price predictions.
- Evaluate prediction performance.

## Approach

The workflow includes:

1. Dataset preparation and exploration.
2. Feature selection.
3. Train-test split.
4. Regression model training.
5. Prediction generation.
6. Model evaluation.
7. Visualization of prediction results.

## Key Concepts

- Supervised Learning
- Regression
- Feature Engineering
- Train-Test Split
- Model Evaluation

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
