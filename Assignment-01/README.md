# Assignment 01 – Car Mileage Estimation

## Overview

This assignment focuses on building a machine learning solution for **car mileage estimation** using automotive-related input features.

The objective is to understand how vehicle characteristics can be used to develop a predictive model for estimating mileage.

## Objective

- Prepare an automotive dataset for machine learning.
- Identify relevant input and target variables.
- Train a regression-based prediction model.
- Evaluate the model using appropriate regression metrics.
- Understand the relationship between vehicle attributes and mileage.

## Approach

The notebook follows a typical machine learning workflow:

1. Load and inspect the dataset.
2. Perform data preprocessing.
3. Select relevant features.
4. Split the data into training and testing sets.
5. Train the predictive model.
6. Generate mileage predictions.
7. Evaluate model performance.
8. Visualize the results.

## Key Concepts

- Supervised Learning
- Regression
- Feature Selection
- Train-Test Split
- Model Evaluation
- Prediction
