# Assignment 02 – Simulated Driving Agent

## Overview

This assignment explores the development of a **simulated driving agent** for an automotive environment.

The objective is to understand how an intelligent system can process driving-related information and make decisions within a simulated environment.

## Objective

- Understand the concept of an intelligent driving agent.
- Process simulated driving inputs.
- Implement decision-making logic.
- Simulate driving-related actions.
- Analyze the behavior of the agent.

## Approach

The workflow involves:

1. Defining the simulated driving environment.
2. Representing relevant vehicle and environment states.
3. Processing input conditions.
4. Applying decision-making logic.
5. Generating appropriate driving actions.
6. Evaluating the resulting behavior.

- Simulation
- Automotive AI
- Rule-Based Logic
