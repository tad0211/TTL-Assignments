# Assignment 03 – Data Cleaning & Preprocessing

## Overview

This assignment focuses on **data cleaning and preprocessing**, which are essential steps before applying machine learning algorithms.

The objective is to transform raw data into a structured and reliable dataset suitable for machine learning.

## Objective

- Inspect raw data.
- Identify missing and inconsistent values.
- Handle data quality issues.
- Transform variables into appropriate formats.
- Prepare the processed dataset for machine learning.

## Approach

The notebook demonstrates a preprocessing workflow involving:

1. Dataset inspection.
2. Identification of missing values.
3. Detection and handling of inconsistent data.
4. Data type processing.
5. Feature transformation.
6. Final dataset validation.

## Key Concepts

- Data Cleaning
- Missing Value Handling
- Data Transformation
- Feature Preprocessing
- Data Validation

- Pandas
