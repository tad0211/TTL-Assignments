# Assignment 07 – Pedestrian Detection using HOG + SVM

## Overview

This assignment implements **pedestrian detection using OpenCV's Histogram of Oriented Gradients (HOG) descriptor and Support Vector Machine (SVM)**.

The objective is to demonstrate a classical computer vision approach for detecting pedestrians in images.

## Objective

- Understand the HOG feature descriptor.
- Use OpenCV's pedestrian detection capabilities.
- Detect pedestrians in input images.
- Draw bounding boxes around detected pedestrians.
- Visualize the detection results.

## Approach

The implementation follows these steps:

1. Load the input image.
2. Initialize the HOG descriptor.
3. Configure the HOG + SVM pedestrian detector.
4. Perform multi-scale pedestrian detection.
5. Generate bounding boxes.
6. Visualize the detected pedestrians.
